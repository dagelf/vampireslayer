# Artwork

`preview.png` is original promotional art generated with the built-in imagegen tool. It is not a screenshot or an existing game's artwork. The README and marketplace use the same asset.

`docs/omarchy-watching.png` is an unedited screenshot of the live Omarchy/Hyprland VNC test, showing the monochrome icon and its operational tooltip. The desktop wallpaper belongs to the installed Omarchy theme.

The bar uses the hand-authored 16-pixel glyphs in `PixelVampire.qml`, monochrome by default. `colorIcons` is an optional Omarchy widget setting. No animations or idle redraw timer run.

Visual references reviewed from the Omarchy marketplace: Navbar Cat's pixel sprite card, Sky Map's dark illustrated panel, and Top 5 Apps Bar's compact screenshot. These were layout/style research only; their artwork was not copied. See [the marketplace](https://plugins.omarchy.org/) and its [development guide](https://plugins.omarchy.org/develop.html).
